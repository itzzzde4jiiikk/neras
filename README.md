# Nera's Discord Stream Chat Overlay 💬

Стрим-оверлей чата Discord для Arch Linux (Hyprland), оформленный в нативном стиле Material You под вашу тему `dots-hyprland`.

## ✨ Возможности
- **Стиль стрим-чата**: Сообщения выводятся в виде парящих карточек с аватаром, ником, временем и текстом прямо поверх всех окон и игр.
- **Интеграция с темой `dots-hyprland`**: Автоматически перехватывает цвета из `~/.local/state/quickshell/user/generated/colors.json` (Matugen). При смене обоев или темы оформления стиль чата обновляется на лету без перезапуска!
- **Click-through (прокликивание)**: Чат не перехватывает клики мыши — вы можете играть или работать, кликая прямо сквозь него.
- **Горячая клавиша в Hyprland**: По бинду `SUPER + U` чат скрывается или появляется на экране.
- **Два режима получения сообщений**:
  1. **Vesktop / Vencord (Без токенов)** — через встроенный плагин `XSOverlay` в Vesktop.
  2. **Discord Gateway (По токену)** — через WebSocket API дискорда (бот или аккаунт с поддержкой подгрузки истории).

### 1. Горячие клавиши

Чтобы проверить, как выглядит чат:


## ⚙️ Настройка (`config.json`)

Откройте `config.json`:
```json
{
  "target_username": "nera",
  "target_user_id": "",
  "discord_token": "",
  "channel_id": "",
  "is_user_token": false,
  "enable_vesktop_bridge": true,
  "position": "bottom-right",
  "margin_x": 24,
  "margin_y": 50,
  "width": 380,
  "max_height": 550,
  "max_messages": 12,
  "click_through": true,
  "auto_hide_seconds": 0,
  "default_visible": false
}
```

### Параметры:
- `target_username` — имя пользователя, чьи сообщения отображать (например `"nera"`).
- `target_user_id` — ID пользователя в Discord (необязательно, если указан `target_username`).
- `position` — позиция на экране: `"bottom-right"`, `"bottom-left"`, `"top-right"`, `"top-left"`.
- `auto_hide_seconds` — если больше `0`, чат автоматически скроется через N секунд после последнего сообщения (как уведомления на стриме). Если `0` — остаётся открытым до нажатия бинда.
- `click_through` — `true` (мышь проходит сквозь чат) или `false`.
- `background_opacity` — прозрачность затемнения за сообщениями (по умолчанию `0.45`, где `0.0` — полностью прозрачно, `1.0` — глухой тёмный фон).

## 🔌 Как подключить Discord

### Вариант А: Через Vesktop (Рекомендуется, без токенов)
Так как у вас установлен **Vesktop**:
1. Откройте **Vesktop** -> **Настройки** (шестерёнка) -> перейдите во вкладку **Vencord Plugins**.
2. Найдите в поиске плагин **XSOverlay** и включите его тумблером (On).
3. Готово! Любое входящее сообщение от нужного пользователя из лички или серверов сразу отправится в оверлей.

### Вариант Б: Через токен Discord Gateway
Если нужно подгружать историю сообщений при запуске или работать автономно:
1. Вставьте токен в поле `"discord_token"` в `config.json`.
2. Если это токен пользователя (user token для чтения личных сообщений), поставьте `"is_user_token": true`.
3. Укажите `"channel_id"` нужного канала или диалога, чтобы при запуске сразу загружались последние 20 сообщений.

## 🛠 Управление

- `./toggle.sh` — переключить видимость / запустить оверлей.
- `./test_msg.sh "текст"` — отправить проверочное сообщение в чат.
- `./stop.sh` — полностью остановить фоновый процесс.
- `.venv/bin/python3 ipc.py status` — узнать статус оверлея.
